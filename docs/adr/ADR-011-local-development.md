# ADR-011: Local development foundation

- Status: Proposed — human review required
- Decision: Docker Compose runs PostgreSQL 18.7, Redis 8.10.3 and Mailpit 1.33.1 by default, bound only to loopback. RabbitMQ 4.4.0 is optional under the `messaging` profile. Kafka is not in the default local stack.
- Applications run on the host or one selected service container during development; do not run all services by default.
- Local secrets generated by `scripts/bootstrap_local.py`; `.env` and `infra/local/secrets/redis.conf` are ignored.
